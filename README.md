# SusunCeritaku
<li>Dibuat sebagai media pembelajaran siswa kelas 2 SD dalam bab Menyusun Cerita.</li>
<li>Terdiri dari file html, yang didalamnya berisi juga css, js jadi satu file. Hal ini agar tidak membingungkan guru dalam menjalankan aplikasinya.</li>
<li>Mengambil sound sebagai efek ketika jawaban benar. Sound diambil dari laman https://pixabay.com/sound-effects/crowd-cheer-in-school-auditorium-236699/ (nama sudah diubah sendiri oleh penulis).</li>
<li>Terdapat 10 cerita berbeda, dan disusun acak setiap ceritanya. Pengecekan jawaban benar (konfeti & suara), dan pengecekan jawaban salah.</li>
